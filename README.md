# Dasto

Личный ИИ-ассистент для Windows. Пишешь задачу, нажимаешь **Старт**, и ИИ сам берёт мышь и клавиатуру: открывает браузер, ищет сервисы, регистрируется, создаёт, загружает. Когда нужен человек (капча, код из SMS, оплата, уточнение), он останавливается и спрашивает.

## Как это работает

1. Приложение делает скриншот экрана.
2. Отправляет его модели Claude (инструмент **computer use**) вместе с задачей.
3. Модель отвечает действием: клик, ввод текста, горячая клавиша, прокрутка.
4. Приложение выполняет действие и снова делает скриншот. Так до конца задачи.

Когда ИИ нужна помощь, он вызывает `ask_user`, и появляется окно:

| Тип | Когда | Что делает пользователь |
|---|---|---|
| `confirm` | оплата, удаление файлов, передача личных данных | «Да» или «Нет» |
| `question` | нужны твои данные (адрес, имя, пароль) | вводит ответ |
| `handoff` | капча, код из SMS, 2FA, проверка личности | делает шаг сам и нажимает «Я сделал, продолжай» |

## Запуск

Нужны Windows 10/11 и [Node.js](https://nodejs.org) 18+.

```bash
git clone https://github.com/masterklick1/dasto.git
cd dasto
npm install
npm start
```

1. Открой **⚙ Настройки**, вставь API-ключ Anthropic (console.anthropic.com), выбери модель.
2. Напиши задачу и нажми **▶ Старт**.

Сборка установщика `.exe`: `npm run dist` (результат в папке `dist/`).

## Управление

- **Ctrl+Shift+X** останавливает ИИ в любой момент.
- Во время работы окно сворачивается в маленькую панель справа внизу. Оно не попадает на скриншоты и не перехватывает клики. Нажимать в нём можно только когда ИИ задаёт вопрос.
- Журнал действий: `%APPDATA%\dasto\logs\`.

## Безопасность

- API-ключ хранится зашифрованным (Windows DPAPI через Electron safeStorage).
- Текст на веб-страницах для ИИ считается недоверенными данными, а не командами (защита от prompt injection, но не абсолютная).
- На оплату, удаление и передачу личных данных ИИ спрашивает подтверждение.
- Капчи и проверки личности ИИ не обходит, а передаёт тебе.
- Есть лимиты шагов и токенов: при достижении ИИ спрашивает, продолжать ли.
- ИИ управляет реальным компьютером. Для рискованных задач используй отдельную учётную запись Windows или виртуальную машину.

## Настройки

- **Модель:** `claude-fable-5-2`, `claude-opus-5-5`, `claude-sonnet-5-5` (по умолчанию), `claude-haiku-5-5`.
- **Версия инструмента и beta-заголовок** (Расширенные): по умолчанию `computer_20250124` и `computer-use-2025-01-24`. Если у выбранной модели другая версия инструмента computer use, поменяй значения по документации https://docs.claude.com.

## Структура

```
main.js              окно, горячая клавиша, связь с интерфейсом
preload.js           безопасный мост между окном и main
src/agent.js         цикл «скриншот → модель → действие»
src/computer.js      скриншоты, мышь, клавиатура
src/input.ps1        PowerShell-помощник для мыши и клавиатуры
src/settings.js      настройки и шифрованное хранение ключа
renderer/            интерфейс
```

## Ограничения первой версии

- Это прототип, не проверенный на реальном Windows-компьютере. Возможны баги.
- Одна модель на всё. В планах: сильная модель планирует, быстрая делает рутину.
- Окна, запущенные от имени администратора, не принимают ввод от обычных программ (ограничение Windows). Для них запусти Dasto от администратора.
- Только основной монитор.
- Правила сайтов (TikTok, YouTube и др.) запрещают массовую автоматизацию. Используй Dasto для своих аккаунтов и в спокойном темпе.
